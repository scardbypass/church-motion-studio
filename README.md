# Church Motion Studio

Windows 10/11 desktop prototype for worship lyric scenes.

## Current working features (v0.1 prototype)
- Import Notepad TXT lyrics; blank lines separate scenes.
- Edit each scene's text, duration, background color and text animation.
- Light and dark themes; local autosave; manual project save/open.
- Live scene preview.

## Not implemented yet
Timeline keyframe editor, transparent/video backgrounds, MP4 rendering, ZIP export, third-party preset import, community library, and the full effects suite shown in the concept image. These are planned and must not be represented as working features.

## Run
Install Node.js 22 LTS. Run `npm install` then `npm start`.
To package on Windows: `npm run dist`.
